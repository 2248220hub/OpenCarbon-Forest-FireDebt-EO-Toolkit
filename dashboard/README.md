|---|---|---|

The **seven-layer map dashboard** (Block 8B) is not stored here: its Earth Engine map tiles are generated on demand and expire, so a saved copy goes blank after a while. Run Block 8B to regenerate it — it is saved to `MyDrive/<DRIVE_DIR>/figures/dashboard_novelty.html`. A screenshot is in [`assets/results/dashboard_map.jpg`](../assets/results/dashboard_map.jpg).
